# Reference Values:

## B787 Throttle:
**Lever Rotational Arc:** 45~55 deg
**Linear Lever Throw:** 90~110 mm
**Detent Layout:** Smooth frictional sweep

## A330/350 Throttle:
**Lever Rotational Arc:** 40~50 deg
**Linear Lever Throw:** 80~95 mm
**Detent Layout:** Gated notches [IDLE-CL-FLX/MCT-TOGA]. Lift-gated reverser

## A321 Throttle:
**Lever Rotational Arc:** 35~45 deg
**Linear Lever Throw:** 70~85 mm
**Detent Layout:** Short throw throttle w/ rigid physical detents [REV-IDLE-CL-(FLX/MCT)-TOGA]


# Math(booooooo):
s = r * θ
> Where:
- s = arc length (linear throw)
- r = radius (lever length) 
- θ = angle (in radians)
